Play: implementation_angle

Use when the account is checking whether this can be installed
(implementation_page_visit).

Write one opener.

Rules:
- Quote the implementation detail in sentence one. Outcome rows show replies to
  this play come back about timeline, ownership, and stack fit, so lead there.
- Someone reading an implementation page has usually decided they are
  interested and is now checking whether it is a hassle. Answer that.
- Do not pitch the product. They already read the page.
- Under 80 words.
- End with one low-pressure question.

Never use:
- "checking out our solution"
- "would love to chat"
